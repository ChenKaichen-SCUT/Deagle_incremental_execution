# D3 原生 SC 理论规则支持清单

以下规则采用 D3 归档版本 1。ProofId 在一次 P0 运行中稳定。声明和理论关系没有 Boolean 子句载荷，最终理由节点才携带原生 SAT 文字。每次运行均检查原始有符号文字流、真实学习结果以及原生安装的静态图收据。

| 声明或推导 | 运行时证据与独立检查 |
|---|---|
| 规则配置、PO、APO | 配置取自同一原生后端和目标配置。PO/APO 叶保留有向端点及关系类别。由配置与声明产生无分支条件的顺序边。APO 合并时记录新增内部方向的实际父链。 |
| RF 激活 | 读写角色、两个事件的 schema、同址、RF 绑定及配置。核对当前的端点到文字及文字到端点两向绑定。有条件的顺序事实以实际 RF 文字为条件。 |
| 写 guard | 使用事件与 guard 的完整绑定。原生常真 guard 没有分支条件。有条件 guard 保留实际极性，D1 跨版本证书还要求 guard 定义与绑定匹配。 |
| 顺序传递 | 实际前驱、当前边及后继引用，以端点依次相接为条件。复制边只有在有相应父证明时取得有效 ID。 |
| 块内方向与块间提升 | 块内方向由实际 APO 及其传递父链支持。块间提升引用原顺序边和两侧完整块证书，独立核对成员所属块、方向、代表元及两块相异。P0/P1 比较覆盖完整成员和内部关系。 |
| WS | 给定 RF(w,r)、活跃的竞争写 v 及顺序 v≺r，推出 v≺w。保存 w、v 的 guard、竞争写 schema、同址、对应 RF 与顺序证明。 |
| FR | 给定 RF(w,r)、活跃的竞争写 v 及顺序 w≺v，推出 r≺v。保存上述局部前提。WS、FR 均要求 w、r、v 三个原生事件两两不同。低层图令同一节点兼任读和竞争写时，保留原生冲突并将理由及后代标记为不可迁移。 |
| 顺序环 | 实际自环，或正反两条首尾相接的有证路径，产生带条件矛盾。冲突分配处逐字面采用原生已取反的冲突子句。 |
| 反向 RF 预防 | 从 r≺w 和假设选择 RF(w,r) 得到矛盾，将条件解除为含否定 RF 的子句。在实际分配处理处使用原生理由的子句极性，保留单位和非单位两种结果。 |
| Boolean 消解及撤销 | 理论理由通过其 ProofId 成为 D2 的实际冲突、传播、根层单位和最小化理由。索引沿同一证明图传播 B 与理论声明的失效，后代学习及被搜索库清除的证明仍可追踪。 |

三元组预防、竞态、动态 CO 以及缺少必要前提的路径仍以不透明理由进入求解。原生建立 CO 覆盖子句时单独登记，包含这类来源的结论沿任意层数继承未知标记。遇到尚未支持的初始根层理论返回而无法解除其条件时，同样保守登记。支持的局部 WS/FR 推导不依赖候选域穷尽。D3 对需要穷尽声明的新增理论规则没有迁移资格。

运行时只保存直接父节点。相同局部规则以操作、端点和完整有序父 ID 判等后共享。RF 和 guard 的分支条件另以共享并集表示。在理由进入 SAT 边界前，逐项比较解除后的条件与真实子句；不一致的理由保留原生结论并标为未知。独立检查器按规则重新推导顺序、活跃条件或矛盾，核对实际子句，与单独在 D1 编译的观察器比较。每个本地事件编号通过一次性原生图收据与差分表绑定。
