## 联合失效与跨版本保留

“结论可映射”只检查结论中所有文字是否有身份。“旧证明保留”还要求实际依赖的全部基础前提仍成立。12 份 D3 原生记录都分别应用了原冻结 D1 差分和本轮改进映射。以下计数在两套差分下相同。

| P0 | 全部学习中结论可映射 | 完整混合中结论可映射 | 混合旧证明幸存，原 D1 → 改进后 | 纯 B 幸存 | 各类旧证明均幸存且结论可译 |
|---|---:|---:|---:|---:|---:|
| fib | 1,003 | 110 / 112 | 90 → 90 | 31 | **121** |
| circular | 71 | 0 / 0 | 0 → 0 | 12 | **12** |
| airline | 0 | 0 / 2,048 | 0 → 0 | 0 | **0** |

- **fib** 有 22 条完整混合证明因 B 退役。其中 9 条只涉及可确认的旧约束消失，3 条只缺其他身份，9 条同时缺门和其他身份，1 条三者兼有。全部经认证的理论声明足以支持这 112 条旧混合证明中的理论部分。永久纯 B 另退役 95 条。
- **circular** 的 4 条永久纯 T 学习均因理论声明未匹配而退役，119 条永久纯 B 学习失去 B 前提。完整混合为零，即使单个理论理由具备完整证书，最终学习仍可能接触未知理论或查询叶。
- **airline** 的 2,048 条完整混合证明中，2,047 条同时失去 B 和 T 支持，1 条只失去 T 支持。每一条都依赖未匹配的 RF 绑定、事件 schema、同址和块证书。1,882 条还依赖未匹配的写 guard，1,821 条还依赖未匹配的 PO。永久纯 B 的 133 条与永久纯 T 的 285 条也均退役。

原因统计保留“已证实变化”和“现有证据不足”两个状态。同一证书可能缺少多类声明，上面的声明明细可重叠。公共 `invalidatedInputs` 用 B、T、查询与不透明来源作种子，访问同一反向索引；独立检查器用父链正向累积失效原因，两条路径按 ProofId 比对了全部 44,029 个实际出生，差异为零。正常复用路径的逐条 SAT、RUP、新 Closure 调用数均为零。[fib 退役分解](evidence/d3/pairs/fib_updates_8/retirement.json) · [circular 退役分解](evidence/d3/pairs/circular-buffer/retirement.json) · [airline 退役分解](evidence/d3/pairs/airline_reservations_6/retirement.json) · [公共接口对照与计时](evidence/d3/public-joint/summary.json)

## 原生记录和一条完整证明

PO/APO 的静态声明、RF 与写 guard 的绑定、事件角色及同址、完整块证书，均在 D2 的 ProofStore 中取得稳定的 32 位 ProofId。Closure 在实际添边、传递、提升、WS/FR 推导和产生冲突或理论赋值的位置添加直接父节点。写入的每个证明有自己的端点、规则和必要前提。分支回溯同步撤销边上的活动引用，已生成的旧证明仍可被后代引用。三元组预防、竞态、动态 CO、缺少侧条件的规则沿实际父链传播不可迁移标记。[原生规则清单](D3-rules.md) · [Closure 推理位置](../../minisat-2.2.1/minisat/core/Closure.cc) · [统一证明库](../../minisat-2.2.1/minisat/core/ProofStore.cc)

## 小实例与修正过的失败

- 4 个独立原生小模型覆盖 16 组差分。对于同一条直接混合学习，改变 B、改变 T、二者同时改变都会撤销。无关 Boolean 修改保留。分拆或合并证明实际用到的块会使证明失效；改动无关块则保留。独立枚举每个 P1 的顺序和布尔赋值，分别得到 16 至 112 个满足模型。[16 组完整观测](evidence/d3/micro-results.json)
- 改变写 guard 极性后，使用该 guard 的 WS 和 FR 理由均由幸存 1 条变为 0 条。WS 的小模型还有可满足的 P1 反例。新增候选写时，使用局部 RF 对和局部顺序的证明可以保留；实际使用旧候选覆盖子句的证明必须撤销。[Guard 枚举与见证](evidence/d3/expanded-domain/guard-review.json)
- 在明确依赖穷尽性的小例中，RF 候选由 `{x#1,x#5}` 扩为 `{x#1,x#4,x#5}`，Boolean 覆盖由 `5∨6` 改为 `5∨6∨8`。原生混合学习单位 #24 退役，独立学习单位 #25 幸存。在全部 8 个 P0 模型、36 个 P1 模型中检查了这两个结论。P1 顺序 `x#4 < x#2 < x#1 < x#5`、真变量 `{4,7,8}` 使 #24 为假、#25 为真。[候选域反例](evidence/d3/expanded-domain/summary.json) · [两条单位的完整父链](evidence/d3/expanded-domain/supports.json)
- 原生作用域测试撤销并重新激活 RF；另一个原生测试使动态 CO 的两个文字都在消解中消失。学习 #9 和经根层简化及较早学习取得的后代 #14 仍因 CO 来源退役。破坏 RF 极性、伪造保留规则、错误提升块、旧格式、错误安装图收据和错误解除计数的六个对照均被拒绝。D2 的 11 个小型 CNF、22 种差分与两个损坏归档也重新验证。[作用域和 CO 原生输出](evidence/d3/native-scope/observations.txt) · [六个拒绝理由](evidence/d3/corruption-results.json)
- 在 `2ffbab74` 上，手工构造的低层 Closure 图可使同一节点兼任读和竞争写。FR 错误认证自环，学习 #16 曾被公共接口标为幸存；独立规则检查要求三个事件互异。最终版本从原生记录位置拒绝认证重合端点。原求解器仍发生同一冲突，直接学习和后续学习均继承不透明来源。三个冻结程序两端均无读写双重角色节点。修正后重新执行了完整采样和检查。[修正前复现](evidence/d3/pre-fix/rmw/observations.txt) · [修正后复现](evidence/d3/native-scope/observations.txt)

## 身份改进

实体对应要求有符号且单射。原生编码器的门必须具有相同算子和全部已对应的输入；重复门只能用两侧唯一的、已锚定的永久输入使用位置消歧。聚合对象以相同 ABI 和类型布局下各视图均可证明的整数前缀配位。指针、填充、缺少身份的动态定义或无法唯一对应的门继续保持未知。

circular 的跨版本永久输入匹配数从 79,087 增至 126,081。D2 永久纯 Boolean 证明实际用到的匹配输入由 630 增至 741，但五条目标旧证明均未恢复，其中四条重复门仍缺唯一锚点，一条依赖不唯一的 `next#23` 动态定义。airline 的 7,906 个自比未知输入有 427 个现在可自比识别，跨版本仍全部未知。从 P0 自比缺失到两侧别名类不齐等各阶段都有原始反例，无法对应不计作真实约束删除。[改进前后数量、复现实例、12 次采集与差分开销](D3-mapping.md)
