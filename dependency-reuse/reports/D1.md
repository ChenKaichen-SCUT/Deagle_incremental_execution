## 回归检查与构建记录

1. 用冻结 fib P0 生成纯重编号清单，同时反转变量编号、改变一部分极性、替换 SSA 和端点名、重编静态点、线程与调用上下文、图节点和地址组。逐一验证 10,062 个配对的精确目标与符号。全部 Boolean 和理论分类与原清单自比一致。

2. 用原生 C 用例增改无关变量，保留 value 上的 RF 绑定。另一次只给写入增加 guard，value#3 从常真 -1 变为本地文字 148，旧绑定撤销，新绑定登记为新增。新文字缺少跨版本对应。同一写读对的 RF 绑定仍匹配。另一个原生用例替换循环归纳变量名称，两个动态写实例及相应 RF 绑定均保留。

3. 构造的清单覆盖别名拆分、常量折叠、有符号映射、重复和含相反文字的子句、查询目标改变、原子块合并和竞争写域扩展。两张旧块证书与扩展前的候选域均失效，原有 RF 保留。动态 CO 夹具只验证来源分类。六次真实运行的动态 CO 新增均为零。缺少 END 的截断文件被拒绝。

4. 初次开发构建缺少 symbolt 的完整类型头文件。初次独立观察构建的局部变量遮蔽了 MiniSat 成员。上游会把 Git 版本描述编入 version.o，第一版提交前后的二进制只在该目标文件上有差异。回边键修正后，再从最终实现提交独立干净构建。开发树的产物与这次构建逐字节相同。正式计数取该提交在完整六组矩阵上的运行，前一次矩阵另存，所有病例均有结果。
