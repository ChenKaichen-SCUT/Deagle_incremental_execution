# D3 residual theory sources

The probe changes only a separately linked D1 observation binary. The actual call sites are numbered against the frozen D1 Closure.cc; the exact patch and modified sources accompany this audit. Each accepted native assignment retains the call site from enqueue through the native duplicate-suppressed pending queue to the emitted SAT clause. Cycle origins are sampled at the native conflict return. All nine sites have distinct identifiers. Empty site counts are explicit empty objects in summary.json.

The complete ordered, signed theory stream and the full ordered CDCL birth/residence/root stream were both byte-identical to the independent published D1 observer. The D3 mixed-1 archive was bound by exact clause and boundary order. Source events that D3 certified continue to be counted by actual call site; only opaque events seed the residual-source masks. All D3 nodes receive their parents' union in topological order. Every learned mask was compared to its independently audited archive unknown-theory flag.

Each boundaries.tsv.gz row is the one-based native boundary ordinal, D3 ProofId, A/C, numeric D1 call site ID, and certified/opaque. Each learned-origin-masks.tsv.gz row is the birth ProofId, all opaque ancestor sites, direct opaque parent sites, and opaque sites inherited through at least one earlier actual CDCL learning. Direct and inherited-through-earlier-learning can overlap. No timing from this additional observer enters the performance matrix.

From a copy of the D3 report and source, invoke python3 -B replay.py TREE D3_EVIDENCE CASE for each frozen case. It restores the exact mixed-1 archive, checks the published signed streams, and independently regenerates all three mask tables. To rebuild the call-site observer from the frozen D1 build, use python3 -B audit.py CHECKED EXPERIMENT_OUT under taskset -c 2. CHECKED is the recorded experiment directory containing final (D3 implementation), observer (original D1 observation source and recipes), final-evidence and final-runs. EXPERIMENT_OUT is a new directory. The earlier D1 build lives under ~/dependency-reuse/rebuild-d1/final.
