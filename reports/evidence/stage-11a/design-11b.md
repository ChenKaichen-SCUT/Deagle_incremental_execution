# 11B 设计草案：在新的求解世代重放已审核的 Closure 推理

## 数据与接口

拟把可持久化的数据限定为事件／原子描述、带条件的结论、证明和反向索引。工作项包含规则版本、推理方向、完整前提、适用内存模型、原生编译配置和语义匹配证据。`(epoch, local_node, literal, CRef)` 只在产生它们的实例内可用。来源未知的 `learnts`、动态 CO 和旧单位默认为拒绝。

| 拟议接口 | 输入与责任 | 成功和失败结果 |
|---|---|---|
| `freeze_declarations` | 从完整 P0/P1 建模的原生交界读事件、类型、地址、guard、PO/APO/RF/CO 绑定及域，保留声明顺序和语义定义。 | 带来源的不可变快照，不封存队列或分配器。缺字段返回原因。 |
| `match_and_diff` | 按出生路径、动态位点、帧、对象和类型精确匹配。源改写的对应须能校验；哈希仅加速查找，命中后逐字段比对。用有向块内序和语义成员集合确定块身份。 | 部分单射、带符号 literal 变换、已核实与未知变化清单。仅数字重合时不准入。 |
| `audit_proof` | 对当前语义和指定目标检验证书。每个节点记录规则、父节点、显式静态叶和条件文字，必要时记录对完整域的依赖。 | 可在 P1 重放的条件命题、或拒绝原因。逻辑结论与把它入本轮 trail 分开。 |
| `begin_epoch` | 拦住上一轮发布，建立 P1 原生对象、私有本地变量、局部图和新输出容器，按完整 P1 输入初始化。 | 校验成功后原子发布 P1 句柄。中断、资源不足、验证失败则丢弃新临时对象。 |
| `propagate_delta` | 对已核实的正向事实按删／加顺序更新，根层事实、选中 RF 和 CO 由本轮输入或赋值触发。 | 固定点、带理由冲突或明确回退。循环饱和仅报告与该规则集有关的结论。 |
| `finish_query` | 绑定本轮目标、假设与目标性质，SAT 后重新提取并校验目标模型、顺序；把 epoch 随结果一起交付。 | SAT 提供本轮结果，UNSAT/UNKNOWN/中断返回无排名。前一次的回调不得写下一次的容器。 |

### 删除、合并和闭包

1. 将两版节点、关系及证书变换到语义命名空间。正向基础事实以语义字段寻址，特殊条件（不同块、候选集完整、地址分区、guard 恒真等）也有独立叶。实际生成 CO 必须保存其触发条件。
2. 收集已删或变化的叶，反向标记所有可达证明。一个事实仅有一份见证时立即撤销；若维护多份，至少有一份可从仍存在的基础事实有限推导才保留。拒绝用互相引用的理由维持事实。先撤销后重新导出，避免同时增删时过早宣布无环。
3. 拆／并块先在所有相交旧新分量重建成员、块内 PO 及可用写集合。重新生成这些分量对外的基础边，重检指向旧块的证明。无索引、缺少跨区边的来源或不能区分显式与合成块时，整张运行期图重建。
4. 用工作队列处理新增／重新得到的顺序。每个新关系既与旧 RF、guard、另一段路径结合，也与本轮新增关系结合。检查块内逆序和商图环，处理有证书的预防子句，再按固定原生模式完成剩余 CO 搜索。即使变化只有一条边，也可能使任意远端节点失效。
5. 到达固定点后检查所有准备发布的根层结论和冲突的证书。当前查询需要处理此前未选的写序，仍调用完整原生决策流程。UNKNOWN、超时、内存预算、证书疑点不转为安全结论。第一版可以始终新建原生对象，只向其中重放有限、已证明的条件引理。随后才评估是否值得增量维护工作队列。

### 对接 activation literals、assumptions 与 CDCL

对布尔版本私有约束采用正向使能 `aᵢ`，提交 $(\neg a_i\lor C)$，对 P1 查询显式假设 $a_1,\neg a_0$ 及规定的目标。共享约束需要语义一致的稳定变量和有符号替换。版本内部变量分别分配私有空间，同一个逻辑原子在新空间重绑定。若退出时应撤销某根单位，它必须有守卫并且在 assumptions 层生效；直接向根层提交已简化单位再试图撤销是不安全的。

SAT 子句的守卫不会自动关闭 Closure 的 PO、已合并的并查集或已点亮的根 guard。启用版本与 `begin_epoch` 必须同步切换；早期方案为每轮新 Closure 加本轮声明。任何在版本 $i$ 下才成立的理论理由都带 $\neg a_i$，或在仅属于该版本的实例中使用。跨版本保留混合学习子句须检查完整解析链（含根单位、子句最小化和理论前提），或在 P1 从头独立证明该子句。解析时各父子句的守卫必须保留，只有有证书的逻辑推导才能消去守卫。未经证实的 Tseitin 位、动态 CO、别名、常量、相反极性均不可按原整数引用。

保留在同一 SAT 对象中的历史带守卫子句，仅在从未做过不可逆的版本私有根简化、命名隔离和所有理论解释也得到守护的情况下有效。现有 MiniSAT 的 `ok`、根 trail、被清理的 clauses、watch lists 和带旧理由的 单位子句 不满足这个前提。11B 首个原型优先采用新分配器、原生新根和 P1 的全新局部对象。稳定变量是**有定义的语义身份**，不要求两个进程内的整数相同。本阶段只验证了说明这一边界的真值表与有限图，没有改造 MiniSAT。

## 工作量与何时值得用

设 $n$ 为事件数、$m$ 为静态声明数、$h\le n^2$ 为已证明的有序对数、$s$ 为保存的证明节点／依赖弧总数、$j$ 为需运行的有界元数规则实例数。保存一份见证的 DAG 和反向索引占 $O(m+h+s)$，存全部替代证明可能指数膨胀。有限原型为便于审核，额外保存每条事实的展开叶集合，最坏达 $O(hm')$，其中 $m'$ 包含 guard、选择和分组前提；应在 11B 改用共享 DAG 或限额。

对声明的完整解码及身份核实至少需读取相关输入；若两版都从头解码，成本为 $O(\text{输入字节})$ 加规范排序。已建立反向索引后，失效遍历为 $O(s_{\rm hit})$。公平工作队列只处理新触发的有界元数规则实例，理想索引下单轮成本为 $O(s_{\rm hit}+j_\Delta+h_\Delta)$ 加匹配、审证及重组开销。全建的对应成本含 $j_{\rm full}$ 和 $h_{\rm full}$。普通稠密传递组合可达 $O(n^3)$；显式逐端点展开双块提升可有 $O(n^4)$ 个候选实例。RF×竞争写、成对 CO 及内存开销需单列。没有该索引和规则调度的现有研究脚本会重新扫描规则，不能据此宣称运行时间达到上述界。

当少数端点改变、依赖闭包只触及小区域、原证明昂贵而在新图审核便宜，且“差分＋失效＋审核＋补传播”的实测成本小于全建时最有希望。重点计量块内／跨块路径生成次数、同址写候选遍历、FR/WS 重新推导、重复冲突证明，而非只数相同边。系统小图累计保住 15,344 次**含派生父项**的事实、撤销同类 3,520 次，说明有真实的可迁移工作，但这是重复实验内的操作数。读写锁两个改型边即足以改变结论，按改边百分比设速度或安全阈值没有依据。[工作量计数](finite-suite.json)

若变化命中高扇出写、并拆大块、改别名或多数证明依赖变化，$j_\Delta$ 可接近 $j_{\rm full}$，全建可能更省。预算按可记录的检查量选择；超限时丢弃缓存，以原 P1、同样的展开、性质和后端完整重建。发布前保留回退原因、独立 fresh 对照和本轮输出。首个验收应包含本文读写锁、FM 两向写序、TACAS 延迟触发、混合 CDCL、根 UNSAT→SAT、交替 assumptions、双 SAT 排名反转和不完整身份负例。是否实施由阶段审查另行决定。
