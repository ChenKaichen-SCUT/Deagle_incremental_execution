# 形式语义 · 版本、排序理论与固定 Deagle

本稿把“重新推理”固定为在同一组有限规则上求全部有根据的结论。严格 SC 给规则提供模型解释；固定源码给出哪些局部规则可识别、哪些对应仍有证明义务。后续等价定理比较两种获得**同一规则闭包**的方法。

## 1. 版本、事件和语义原子

**定义 1（查询）。** 对 $v\in\{0,1\}$，$\mathcal P_v=(B_v,D_v,Q_v)$。$B_v$ 包含完整布尔化的控制流、数据流、类型运算、读值相等及编码实际提供的选择约束。$Q_v$ 指明被询问的性质、方向和本轮假设。例如寻找违反性质 $\varphi$ 的执行时，查询中编码的是相应错误目标。下文用 $q_v$ 表示这些条件的布尔公式。每一版本的对照都使用完全相同的 $B_v,D_v,Q_v$；不要求 $B_0=B_1$。$D_v$ 由下列有类型的声明构成。

| 记号 | 数学对象及其作用 |
|---|---|
| $\mathcal T,E,\theta,\tau$ | 有限线程实例集、有限动态事件集、所属线程、事件种类。动态身份由线程出生链、创建点及其动态出现次序、函数调用及展开实例、操作位点和读／写／同步角色组成。同一静态写的两次循环执行可以是两个事件。另设地址初始写。 |
| $\mathrm{spawn},P,J$ | 创建事件与子线程实例的配对、线程内 PO 声明、已证的跨线程先后（如创建到子线程入口、结束到成功 join 返回）。证明需记录使这种结构先后成立的线程库及路径语义。 |
| $\lambda,\mathsf{ty},g,\nu$ | 访问的存储对象及范围、类型（含位宽和访问粒度）、使能条件和读／写值术语。基本域限于无撕裂的独立存储单元；相同字节范围和已证的值表示转换才能支持同址规则。位偏移、重叠、大小或别名未经解释时，不生成该同址前提。 |
| $A,\mathcal K$ | APO 是有向的结构顺序。$\mathcal K$ 给出带种类、成员和块内顺序的连续性声明。活动成员组成分划，普通事件视作单点。由 APO 生成块时，需对**全部**相关 APO 求无向连通分量，同时保存有向内部顺序。显式区段、前端合成区段及诊断编号分别标识。 |
| $F_r,W_a,C_a$ | $F_r$ 是读 $r$ 的允许来源；$W_a$ 为单元 $a$ 的全部声明写，含初始写 $i_a$；$C_a$ 是声明或由已知语义生成规则解释的候选写序方向。成员资格不蕴含已选中或活动。 |
| $\beta,I,M$ | $\beta$ 把语义原子联系到本版本带符号的局部 literal 或布尔常量。$I$ 指明初始值、首写和作用域，$M$ 指明内存模型、SC 观察粒度、原子函数解释、线程模型和展开边界。 |

**定义 2（绑定与激活）。** 布尔环境 $\alpha$ 是对 P1 或 P0 本地变量的赋值。对语义原子 $t$，需知道定义、端点、变量及极性，使 $\llbracket\beta(t)\rrbracket_\alpha$ 有确定含义。若多个原子使用同一变量，它们构成带相对极性的别名组；数值相同的常量和同名变量须区分。$g(e)$ 表示 $e$ 出现，$\mathrm{SelRF}(w,r)$ 表示实际选择读源，$\mathrm{SelCO}(u,v)$ 表示实际选择的写序方向。$F_r$ 及 $C_a$ 是候选，$\mathrm{Sel}$ 是取值谓词；由推导得出的两写前后关系也不自动成为一个已赋真的 SAT literal。允许某些原生写序变量在搜索中才分配；若无法给它的定义与作用域命名，该变量不进入可迁移签名。

$\Gamma$ 可以是部分赋值，只接纳本轮已确认的假设或后果。例如，$\mathrm{On}(e)$ 的凭据记录 $g(e)$、其绑定以及使其成立的条件。在仅当完整编码保证 $\mathrm{SelRF}(w,r)\Rightarrow g(w)\land g(r)$ 时，才可由该蕴含产生两端活动的凭据。$\neg\mathrm{SelRF}(w,r)$ 与尚未选中该候选是不同状态。为处理理论冲突，允许在反证所设的条件下进行同一套推理。

## 2. 六个不同层次

| 层 | 所含对象 | 跨版本比较单位 |
|---|---|---|
| 声明 $D$ | 事件、布局、固定结构、带条件的关系、域与绑定的定义 | 有类型的语义声明及其解释范围 |
| 当前基础 $A_v$ | 静态声明的具名事实，以及 $D_v,B_v,\Gamma_v$ 下有凭据的使能、选择、排除等条件 | 完整前提及其逻辑条件。对基础带不同来源的情况可显式外化为不同标签 |
| 推导 | 在规则集合 $R$ 下有有限证明的路径、排序、FR/WS 等 | 语义事实；证明说明为何成立 |
| 冲突 | 如从当前条件得出 $e\prec e$，以专门诊断原子 $\bot$ 标记，并保留支持 | 条件矛盾的推导。系统没有从 $\bot$ 推出任意事实的规则 |
| 已学习命题 | 理论冲突产生的条件子句，或与布尔子句经解析、最小化等生成的结论 | 有作用域的布尔命题及其证明 |
| 求解器临时状态 | 并查集代表、位图、被删候选、队列、trail、根赋值、模型、排名、引用及搜索启发值 | 属于一次运行，未赋予可跨版保留的理论事实身份 |

## 3. 严格 SC 的模型与条件声明

**定义 3（本文所用的严格 SC）。** 一个模型含布尔赋值 $\alpha\models B_v\land q_v$，活动事件 $E_\alpha=\{e:g(e)[\alpha]\}$ 及其严格全序 $L$。初始写始终活动，属于单点块，并依 $I$ 排在所有相关普通访问之前。线程内活动事件的次序扩展该线程的程序顺序；出生、join 等结构和已激活的条件先后均须满足。每个活动块为 $L$ 中的区间，且扩展块内顺序。每个活动读恰选一个活动同址写，属于 $F_r$，其值在 $B_v$ 中吻合，且该写是 $L$ 中读之前最近的同址写。每单元实际 $ws$ 是 $L$ 限制到活动写所成的严格全序，已选择的 $co$ 方向均须满足。$fr=rf^{-1};ws$，其中 $rf$ 从写指向读。这是单不可分存储单元及显式连续块的 SC；语言级数据竞争未定义行为、逐字节拼接的 RF、弱内存屏障语义须有不同的解释。

为避免对未出现的中间点作出错误推论，把 $P,A,J$ 中**无条件结构先后**视作潜在事件序列的约束。例如同一时序中若 $a$ 在可选操作 $b$ 之前、$b$ 在 $c$ 之前，则 $a,c$ 都出现时，结构顺序仍要求 $a<c$。将这种边的非空路径投影到活动端点。依赖某次成功加锁或另一条件的边单独标为 $\mathrm{IfOrd}(t,a,b)$，只在 $t,a,b$ 均已使能时转为活动排序。没有无条件结构解释的边不能跨未活动中点投影。

$T_{\rm SC}(D)$ 指上述与 $D$ 有关的执行条件，$B,q$ 由外层合取。全模型的所有 RF/WS 等选择必须齐备；部分 $\Gamma$ 下的后果指**所有延拓模型**均成立的命题。一条规则可靠，只要求每个满足其前件的模型满足其后件。仅凭已推导集合没有 $\bot$，一般不能给出这样的模型。

## 4. 本阶段的精确规则集合

**定义 4（有限正向 OC 子演算 $R$）。** 令 $H_v$ 为下表在本版本有限有类型签名上的全部具名基实例。每一行是有前件、结论和作用范围的 Horn 蕴含。$\mathsf{Pth}$ 表示无条件结构路径，$\mathsf{Ord}$ 表示活动事件的必要先后。$\mathrm{EligibleRF}$ 须记录声明、写／读角色和同址单元，$\mathrm{EligibleCO}$ 须记录两个不同的同址写与方向声明。$\mathrm{Competitor}(u,w,r)$ 包含 $u\ne w$、三者属同一单元、$u,w$ 为写且 $r$ 为读。为便于阅读，下表逐行省略的事件存在及类型凭据也属于带标签的基础前提。可将不可变的有类型匹配条件写入基实例标签；类型／解释变化时，旧实例须随之失效。

| 名称 | 前件 | 结论 |
|---|---|---|
| 结构边与路径 | $K(x,y)$，其中 $K$ 是无条件 $P,A,J$ 或初始先后；或者 $\mathsf{Pth}(x,y),\mathsf{Pth}(y,z)$ | 对应地推出 $\mathsf{Pth}(x,y)$ 或 $\mathsf{Pth}(x,z)$ |
| 活动投影与条件边 | $\mathsf{Pth}(x,y),\mathrm{On}(x),\mathrm{On}(y)$；或者 $\mathrm{IfOrd}(t,x,y),\mathrm{True}(t),\mathrm{On}(x),\mathrm{On}(y)$ | $\mathsf{Ord}(x,y)$ |
| 已选 RF | $\mathrm{EligibleRF}(w,r),\mathrm{SelRF}(w,r),\mathrm{On}(w),\mathrm{On}(r)$ | $\mathrm{RF}(w,r)$；再由 $\mathrm{RF}(w,r)$ 推出 $\mathsf{Ord}(w,r)$ |
| 已选 CO | $\mathrm{EligibleCO}(u,w),\mathrm{SelCO}(u,w),\mathrm{On}(u),\mathrm{On}(w)$ | $\mathrm{WS}(u,w)$ |
| WS 推导 | $\mathrm{RF}(w,r),\mathsf{Ord}(u,r),\mathrm{On}(u),\mathrm{Competitor}(u,w,r)$ | $\mathrm{WS}(u,w)$ |
| FR 推导 | $\mathrm{RF}(w,r),\mathsf{Ord}(w,u),\mathrm{On}(u),\mathrm{Competitor}(u,w,r)$ | $\mathrm{FR}(r,u)$ |
| 排序与传递 | $\mathrm{WS}(x,y)$ 或 $\mathrm{FR}(x,y)$（各一条规则）；或者 $\mathsf{Ord}(x,y),\mathsf{Ord}(y,z)$ | 对应地推出 $\mathsf{Ord}(x,y)$ 或 $\mathsf{Ord}(x,z)$ |
| 跨块提升 | $\mathsf{Ord}(a,b)$，$a,x$ 属已核实的同一块 $K$，$b,y$ 属已核实的同一块 $L$，有 $K,L$ 不同且各自连续的凭据，$\mathrm{On}(x),\mathrm{On}(y)$ | $\mathsf{Ord}(x,y)$ |
| 环 | $\mathsf{Ord}(x,x)$ | $\bot$ |

不同块的证明不能取自两个代表元的数值不等。在由 APO 生成分划的情形，使用带种类和**完整语义成员集**的块声明，或能从 P1 重证的同块、异块与连续性凭据。新路径合并块时，端点之外的旧提升实例也可能失效。结构路径 $\mathsf{Pth}$ 是对声明的关系判断；经过未活动点并不表示这些点实际执行。

**可选扩充 $R_{\rm dom}$。** 若另有经证明的全称声明“读 $r$ 在此作用域活动时，恰从完整候选集合 $K$ 中选择一项”，可加入具名规则族。对 $w\in K$，以 $\mathrm{On}(r)$、完整域凭据 $\mathrm{ExactOne}(r,K,\mathrm{scope})$、作用域为真、每个 $u\in K\setminus\{w\}$ 的显式排除 $\neg\mathrm{SelRF}(u,r)$ 为前件，推出 $\mathrm{SelRF}(w,r)$。若所有 $u\in K$ 都被显式排除，则可推出 $\bot$，其中包括经认证的 $K=\varnothing$。排除项在 Horn 系统中是带符号的**正输入原子**，其解释是相反布尔命题已获证明。仅对完整成员集与使能作用域均可重新认证的场合生成这些实例。原生后端未被假定实现这一附加族。下文定理可固定使用 $R$，也可在两侧一致地使用 $R\cup R_{\rm dom}$。

**定义 5（闭包）。** 对基事实 $A_v$ 和基实例 $H_v$，令 $X_0=A_v$，并递推

$$X_{j+1}=X_j\cup\{h:(P\to h)\in H_v,\ P\subseteq X_j\},\qquad
\operatorname{Cl}_R(D_v,\Gamma_v)=\bigcup_{j\ge0}X_j.$$

同一带符号前提的真假、候选集合完整、不同块等判断均在规则作用域或基础前提中留痕。当 $H$ 固定时，当前件均为正原子，$X\subseteq Y$ 蕴含每个在 $X$ 可触发的实例在 $Y$ 也可触发，故一步算子单调。有限原子域保证在有限次严格增长后停在固定点。对任何含 $A_v$ 且对 $H_v$ 封闭的 $Z$，从 $X_0\subseteq Z$ 对 $j$ 归纳可得 $X_j\subseteq Z$，故该固定点最小。公平顺序只加入已有前提成立的头，归纳说明不会越过最小固定点；公平性又保证每层有限推导最终加入，因而顺序不影响结果。跨版本可能同时改变 $A$ 及 $H$，该单调性仅适用于固定输入内部的饱和。

**规则的严格 SC 解释。** RF 与 CO 的给定方向、投影后的结构关系及传递均是模型定义所要求。若 $r$ 读自 $w$ 而另有同址写 $u$ 在 $r$ 前，则 $u$ 若在 $w$ 后会覆盖 $w$，故 $u$ 必在 $w$ 前。若 $u$ 在 $w$ 后，则同理 $r$ 须在 $u$ 前。两个不相交的非空区间在全序中有唯一的块间先后，一对成员的跨区排序足以确定所有活动成员的跨区排序。$\mathsf{Ord}(x,x)$ 排除了严格全序。完整域规则源于有限非空选择的排中与已证排除。由此，每个导出活动排序在全部严格 SC 延拓中成立。对部分赋值，即使闭包中没有环，尚未决定的同址写总序仍可能没有一致延拓。T8 所用特殊条件是已给定全部活动事件、每读唯一来源、每址全部写的总序及初始顺序、真实的块分划和全部所需结构约束，并已满足其余布尔条件；相应结论见定理稿。

## 5. 跨版本变化的解释

把部分单射 $\sigma:E_0\rightharpoonup E_1$ 扩展到已证明对应的线程、对象、角色、类型、块及逻辑原子。比对凭据须能保持线程出生链、动态实例、读写角色和地址解释。身份可由重命名的双向解释证明；若程序修改保留一个操作的比较角色但改变其控制条件，guard 和与之相关的规则仍须另行核实。为每个无法匹配的旧名保留独立的旧版专属名，为每个无法匹配的新名保留新的专属名，在共同签名中计算 $\Delta^-=\bar D_0\setminus D_1$ 与 $\Delta^+=D_1\setminus\bar D_0$。于是 $D_1=(\bar D_0\setminus\Delta^-)\cup\Delta^+$。被删的身份标签、改变的谓词解释和动态条件须继续投影为 $A,H$ 的实际差分；只计算文本边差尚不足以定义更新。

| 变化 | 必须反映的语义变化 | 单调性条件 |
|---|---|---|
| A、B 增删 PO/APO | 结构边的有向标签以及通过该边的路径；若影响块则同时改变分划和提升实例 | 固定域及分划下纯 PO 增加可扩张正闭包，删除可收缩。APO 添加若合并块通常还删除旧的异块前提 |
| C 改型 PO↔APO | 旧类型撤销、新类型加入，重核块内次序与块间关系 | 两类边均表达先后，只有 APO 还可能改变连续性。整体按非单调处理 |
| D 来源和域 | 允许域、已选 RF、全部被排除候选以及读取值在新 $B$ 下的解释 | 单独替换已选来源是删加；扩张候选集合还可能撤销原来的唯一选源证明 |
| E guard | 定义、极性、别名组、使能的逻辑条件及 $\Gamma$ 下真假 | 固定解释的真实基础增加为正向；改定义或翻转赋值为非单调 |
| F 块合并／拆分／移出成员 | 旧、新块成员、方向、区间语义、异块凭据及所有使用它们的跨块规则 | 需要同时删除和新增规则实例。仅重置被移动的一个端点不充分 |
| G 事件增删／重命名／失配 | 事件角色、出生、定义域、涉及该事件的所有多元组 | 纯同构重命名保持语义；加入写还可能改变旧域的完整性；无匹配按专属身份处理 |
| H 别名／访问粒度 | 地址等价类、写候选、值解释和所有同址规则 | 重新认证实际存储单元。若存在部分重叠或读撕裂且无原子单元解释，拒绝该处规则迁移 |
| I WS/CO | 可比较的动态写和使能、方向语义、候选域、给定或撤回的顺序 | 增加同一签名的已选方向可增加正事实；新增候选与新增已选方向有不同含义，替换决定属非单调 |

增加理论约束可能使原本允许的布尔赋值不再有模型。即使旧无条件先后在逻辑上仍真，也不能把旧模型、已选决策或一次运行的队列作为新版本的有效状态。
