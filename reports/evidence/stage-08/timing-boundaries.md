# 阶段 7 计时审查与阶段 8 测量边界

核查基线为项目提交 `247894bf77904bb34e547b5a636b8afe8527add4`。阶段 7 独立基线为 `a159f992`，增强基线为 `0be9e216`。两个执行路径最终使用同一候选、同一 harness、SC、Closure、64 位模型、同一展开界限和展开断言。每条路径单独解析目标性质与必要的反例。[阶段 7 测量控制器](../../../scripts/stage7/worker.py) · [调度及取样](../../../scripts/stage7/experiment.py) · [统计](../../../scripts/stage7/results.py)

## 阶段 7 的时钟

| 量 | 起点与终点 | 已计入与边界 |
|---|---|---|
| 完整候选 `T_full` | `plain()` 在建立空验证目录后取 `full_start`，写完性质结果后取 `full_end` | 复制并校验两份源文件、哈希独立二进制、启动 timeout 和原生进程、预处理至求解、结构化输出、检查 Closure 标记、再次读源码哈希、解析并在需要时规范化反例。服务启动、Python 导入、读取 task/gamma/phi 和创建空目录在时钟前 |
| 增量候选 `T_inc` | `FrozenReplay.produce()` 在确认旧反例、旧缓存及驻留进程后记录 `incremental_start`，`incremental()` 再次确认封存输入并写完候选结果后记录 `incremental_end` | 冻结候选复制与哈希、候选前端进程、准入、旧新 manifest、源码和 GOTO 对应、管道请求、原生恢复或回退、理论审核和导入、求解、会话收尾及多次结果解析在内 |
| 旧程序两种成本 | 普通旧验证使用 `old_full_start/end`。采集旧状态从 `old_instrumented_start` 至同一提交候选的边界 | 后者含准备快照、校验二进制、生成旧模型、原生 fork、旧求解、构造理论证书、规范化并绑定旧反例。建立一次旧会话只服务一个 P1 |
| 内部候选墙钟 | `stage4.session.run_pair` 中另取 `update_start`，在最后一次原生分类后取结束时间 | 内嵌在外层 T_inc 中。恢复时原生旧进程继续运行，回退时另起一次增强版完整验证。内部时钟不包含全部外层封存、清理和结果核对 |
| 前端墙钟 | 在 `start(front)` 前取单调时间，`compiler.wait(timeout=remaining())` 返回后结束 | 包含启动进程、三类前端工作、观察输出、序列化、进程退出及控制器发现退出的延迟。之后的 `admit()` 和 `candidate_context()` 另计 |
| 额外正确性检查 | 原生外运行第二个观察版全量 P1，之后比较四个阶段 | 阶段 7 的正式候选墙钟排除了这次完整复查。增量算法准备缓存及证书所需要的观察 JSON、IREP 和辅助进程仍计入 T_inc |
| 完整周期 | 普通或采集旧验证 + 同一次修复成本 + 对应候选验证 | 实测补丁重放与历史 AI 时间是两种报告口径。编译、API 及离线分析不进入候选时钟 |
| 资源 | cgroup v2 `cpu.stat` 差值，目标 5 ms 的外部取样 | 取样覆盖父、子进程。RSS 求和可能重复计算共享页，cgroup 记账还包含文件页。旧快照驻留在候选时段 |

`T_full` 与 `T_inc` 均包括执行路径必须支付的复制、哈希、等待及输出成本。公平性来自验证目标及外层用户操作一致。控制器的数据记录工作、预处理包装器、独立 P0 准备、两套原生程序的搜索行为均可能造成差异。原始实现中对恢复候选的文本 `Runtime Symex` 起点可能继承自 fork 之前。阶段 8 直接在每次原生指令分派周围累计 CPU 与墙钟，并在接收恢复命令后切换统计目标。[原生检查点实现](../../../patches/deagle-stage04-incremental.patch) · [阶段 7 原始时钟](../stage-07/measurements.json)

## 阶段 8 的对照

| 模式 | 原生与控制器行为 | 验收依据 |
|---|---|---|
| F0 | 普通组使用未修改的阶段 7 原始完整验证器。详细组使用从同一原始提交构建的测量版 | 每次校验二进制、P0、P1、性质与反例。另设同一原始测量版开关诊断对照 |
| F1 | 增强诊断二进制，普通完整 P0 加完整 P1 | 无旧版本状态。与 F2、I1、I2、I3 共用一个增强二进制 |
| F2 | 采集与审核旧状态，提交候选前端，完成变化分析，再要求候选完整重建 | 已存在的拒绝原因优先。适用更新的病例记录显式强制回退。候选执行完整分派与 SC 生成 |
| I1 | 在有效检查点恢复，只复用原生符号执行前缀。恢复的候选执行完整 RF 和 PO 生成 | 关闭候选片段命中后进入原完整生成代码。仍审核历史引理并记录计划，向求解器提交空计划 |
| I2 | 支持的前缀及 SC 片段均复用，仍审核引理并向求解器提交空计划 | 以有符号绑定计划和原生导入回执区分“审核通过”和“已导入” |
| I3 | 运行阶段 7 的原有检查、片段复用、回退和真实引理导入 | 验证原生执行、实际导入数及冻结性质。同步变化在 I1–I3 均保留完整回退 |

F2、I1、I2 为保持可比性支付同样的候选证书审核成本。因此 I3−I2 隔离的是在审核已经完成后提交引理的净变化。F2−F1 同时包括完整包装流程、额外前端、观测、理论审核以及可能的搜索变化。F2−I1 还包括避免再次启动完整候选进程的收益。专门的原生前缀与地址桶计时用于估算跳过的计算。[原生开关与计时位置](../../../scripts/stage8/instrument.py) · [受控工作进程](../../../scripts/stage8/worker.py)

## 父子时间和单位

| 原生父阶段 | 子阶段或并列阶段 | 解释 |
|---|---|---|
| `get_goto_program` | `preprocess`、C parse、typecheck、goto_convert，以及包含若干前述调用的 `process_goto_program` | 前四项用于分解父阶段。process_goto_program 是另一种观察视角，含库建模调用，不再与这四项相加。GOTO JSON、构造原生 image、写 IREP 在该父阶段之后 |
| 原生符号执行 | 候选完整运行的前 N 次分派与其余分派，按单调墙钟及本进程 CPU 分别计量 | N 为同病例经阶段 7 原生执行证明的前缀长度。恢复进程单独累积后缀。指令分派数与耗时分别报告 |
| SC 模型 | 事件表、RF、PO/APO、被复用键的原始生成、资格检查和重绑定 | 在同一候选完整运行上，以已证实命中的地址桶和线程键计量原先的一段生成工作。RF/PO 包含桶或线程、资格与重放等子项 |
| SSA 到求解器准备 | SSA 位级转换、图和 guard 的转换装载、候选 OC 快照和辅助审核 | `encode_graph` 包含审核。成本账本扣除内部 `lemma_prepare` 后单列编码。`ssa_convert` 与 `graph_load` 用于解释，不与父阶段重复相加 |
| 求解器 | 原生 Runtime Solver、`ClosureSolver::search`、首次搜索前的引理提交 | 总求解扣除提交后进入账本。搜索次数、决策、冲突、传播均独立记录。早退时未输出的全局传播计数为空 |
| 理论维护 | 原生建图快照、调用 Python 审核器并等待、候选上下文规范化、校验证书、绑定符号、提交 | 进程墙钟包含 Python 解释器启动。Python 记录各函数的包含和独占墙钟与 CPU。旧证书与候选证书分开 |
| 检查点与文件 | 原生采集含 fork、恢复时加载 GOTO 与片段 IREP、rebind、符号检查 | 解释时使用生产路径的合计和独立编解码微基准。写入返回统计至 close，未要求 fsync。微基准时间独立于正式计时 |
| 控制器与资源 | 复制、哈希、manifest、解析、Popen 和 wait，cgroup CPU/I/O、组内 RSS/进程数、驻留检查点 PSS | 普通组保留轻量边界与资源采集。详细组额外采原生函数和 Python 独占时间。pidfd 退出观测与 strace 各自另跑 |

原生探针使用 `CLOCK_MONOTONIC` 和 `CLOCK_PROCESS_CPUTIME_ID`，Python 使用单调时钟和进程 CPU。CPU 时间不含其他进程，cgroup CPU 覆盖包括 GCC、Python 审核器在内的整个服务。原生高频分派只累加，搜索前缀最多记录 32 次决策和 16 个冲突。完整有序输入流只在独立深度诊断中写出。[计时实现](../../../scripts/stage8/meter.h) · [独立前端测量](../../../scripts/stage8/frontend_probe.py)

成本账本按相同病例、模式和重复号先作差。每个详细候选分别计算前端、指令分派、SC、纯编码及图、求解、恢复、变化分析、理论、观测与剩余。剩余等于外层墙钟减去以上互不重复的项，含未单列的等待、退出、内存管理、其他控制器和系统噪声。带符号的均值可以逐列相加，分项中位数不满足这一性质。普通与详细路径的总时间分别报告，系统调用跟踪数据单列。[统计脚本](../../../scripts/stage8/statistics8.py) · [消融逐次数据](ablation-results.csv)
