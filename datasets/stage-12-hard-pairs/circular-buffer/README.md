# circular-buffer

轮询失败也推进了载荷编号。修复让七次轮询照常执行，生产和消费各在事务成功后推进序号。

原性质由 YAML 的 unreach-call.prp 指定。两端均按 ILP32、SC 和展开 8 从头建模，执行全部原生性质及展开检查。

| 版本 | 结论 | 服务器纯搜索秒 | CDCL 冲突 | 理论冲突 |
|---|---|---:|---:|---:|
| P0 | SAT | 0.392837 | 343 | 18 |
| P1 | UNSAT | 13.081367 | 7525 | 56 |

P0 产生 343 条 CDCL 第一 UIP 学习记录。已确认 0 个有符号变量对应和 0 条保留原始子句（按重数）。原始宿主上的时间见 baseline.json，原始公式、图和轨迹见阶段证据索引。模型差分仅确认通过签名和语义身份核对的部分；未映射项单独计数。

Windows 工作区运行 `.\deagle-local.cmd hard-pair circular-buffer`。
